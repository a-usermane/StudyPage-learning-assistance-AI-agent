# 课程书桌：本地学习空间

按课程管理资料、聊天和笔记。支持可配置的 Deep Agents 文件问答、独立翻译与解释、Skill、只读 MCP 和本地插件。新增依赖、缓存、文件和数据库保存在 D:\note；默认演示模式，不执行上传代码。接入与扩展说明见 [AGENT.md](AGENT.md)。

## 启动

首次使用 Agent 版本先运行 setup.cmd 安装锁定依赖；本次开发环境已经安装。日常在 PowerShell 中：

```powershell
Set-Location D:\note
.\start.cmd
```

也可双击 start.cmd。服务只监听 127.0.0.1:8000。阅读与演示模式可离线运行；真实 AI 使用你配置的 API。保留终端窗口，Ctrl+C 停止。端口占用会报错，不会停止其他程序。

## 使用

1. 起始页选择“新建课程”，填写名称，选择多份资料，逐项选择课件、练习、作业、代码或其他。
2. 点击“导入并进入课程”。至少一份成功即可进入；失败项列在课程页，可重新选择修复后的文件重试。失败队列仅在当前网页会话保留；刷新后可以通过“文件 → 在此项目中添加资料”重新选择，成功资料会长期保存。
3. 最左侧按钮分别返回起始页、打开插件说明、开关课程菜单，底部设置页可切换模式、重载配置和诊断模型连接。课程菜单可以切换课程。
4. 课程名称显示在对话区顶部，追加资料通过“文件 → 在此项目中添加资料”。对话在左、资料在右；拖动分隔线改变宽度，“视图”菜单可交换左右。窄屏使用对话/资料标签切换。
5. 文件名位于资料区首行，下拉列表按用途分组。PDF/PPTX 连续滚动阅读，页码在内容或底部显示。缩放不修改原文件。
6. 划词翻译默认关闭：划词后显示解释、提问、保存笔记。开启后直接弹出翻译框。弹窗顶部“翻译、解释、提问、笔记”显示当前状态，同一选区切换时保留回复和输入草稿。选区可跨同一文件的多页，上限 5000 字符。
   输入区域默认收起，点击后展开；点击“收起”保留草稿。翻译、解释的追问留在各自会话。笔记可附带已有回复，演示内容会标注。切换文件或关闭弹窗取消旧请求并丢弃未保存草稿。转入主对话复制原回复及来源，不重复调用模型。
7. 每门课程共用聊天记录，切换文件保留聊天。发送时固定当前页或所选位置；AI 优先当前文件，必要时搜索同课程其他资料。无当前文件也能对课程提问。点击来源返回页码或代码行；“停止”取消生成，失败可重试。
8. 笔记按课程显示，可勾选“仅当前文件”。可保存原文、回复和自己的理解。删除资料保留聊天和笔记，来源显示“原资料已删除”，该资料从搜索索引移除。
9. 刷新课程页会恢复课程、文件及阅读位置；直接打开根地址显示起始页。布局和翻译开关保存在浏览器本地。课程栏展开/收回带动画，开启系统“减少动态效果”时关闭动画；主输入框自动增高。

## 数据和旧版迁移

```text
D:\note\
├─ backend\
│  ├─ domain\      实体、规则、业务错误与接口
│  ├─ service\     课程、导入、问答和笔记用例
│  ├─ api\         HTTP 模型、路由与请求大小限制
│  ├─ dp\          SQLite、检索、模型、Deep Agents、MCP 与配置适配
│  ├─ config.py     配置
│  └─ app.py        应用工厂与依赖装配
├─ frontend\
│  ├─ pages\       起始页与课程工作区
│  ├─ components\  布局、上传、对话和选区组件
│  ├─ readers\     PDF/文本阅读器，共用来源操作
│  ├─ services\    API 客户端
│  ├─ state\       状态与本地偏好
│  ├─ shared\      DOM 与通用展示
│  ├─ styles\      基础、设计变量、外框布局和组件样式
│  └─ vendor\      完整本地 PDF.js
├─ data\
│  ├─ db\library.db
│  ├─ db\agent-sessions.db 内部消息、摘要、工具结果和运行状态
│  ├─ db\checkpoints.db    LangGraph 运行中 checkpoint
│  ├─ courses\<课程ID>\materials\<用途>\<资料ID>\original.<扩展名>
│  └─ backups\legacy-v1\  旧库快照、旧原文件与迁移清单
├─ .cache\          临时上传、验证数据和日志
├─ .venv\           项目虚拟环境
├─ samples\         可导入的验证资料
├─ config\          模型、流程和 MCP 配置
├─ prompts\         通用规则与四种功能提示词
├─ skills\          SKILL.md 及参考资料
├─ plugins\         本地插件 manifest
├─ examples\        离线术语 MCP 示例
├─ tests\           单元、迁移、上传传输和接口测试
└─ scripts\         环境准备与启动
```

依赖方向：api → service → domain；dp 实现 domain 接口；app.py 装配具体实现。service 不导入 FastAPI、SQLite 或格式解析包，可用模拟依赖测试。

SQLite 保存分页提取文本、课程、资料信息、聊天、笔记。磁盘保存原文件，不重复生成笔记 JSON。相同文件名允许上传，用不同 ID 隔离。

首次启动新版会备份旧数据，将旧资料统一归入“历史资料”，保留原 ID 和记录。代码归代码，其他旧文件归其他。复制后校验哈希、数量与外键，成功才切换；中断可重试。旧数据库和原文件归档至 backups，不自动清理。备份会额外占用 D 盘空间。备份项目时应停止服务后复制整个 data 目录。

## 限制

- 不包含向量检索、OCR、账号、插件市场、可视化流程编辑器或自动多 Agent 委派。
- 演示模式只展示词典、问题和原文，未知内容不生成假解释。真实模式受模型效果影响；来源验证保证引用存在，不能保证结论一定正确。
- 首版总结当前页有界片段，过长内容注明范围；无正文页直接提示无法总结。
- PDF 保留版面与文字层；扫描 PDF 可预览但不能划出图片中的文字。PPTX 只提取文字、表格和已有备注。
- Markdown 按纯文本阅读；代码只读、有行号，没有调用外部编辑器或执行功能。
- 默认单文件最多 20 MB，最多 1000 页/幻灯片；文本 200 万字符，总提取文字 500 万字符。损坏、加密或不支持格式显示错误。
- 来源保存文件名和起止页码，不持久保存选区坐标或高亮。

默认上限集中在配置中。需要临时调整时，在启动前设置进程环境变量，例如：

```powershell
$env:STUDY_UPLOAD_LIMIT_MB = "50"
.\start.cmd
```

该设置不会修改系统环境变量；大文件解析仍受上述文字和页数上限约束。

## 验证

单元、仓储、迁移与原始上传请求测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

隔离数据目录的离线接口测试（自动启动本机 8001 端口，阻止服务端外部网络）：

```powershell
.\.venv\Scripts\python.exe tests\offline_check.py
```

测试结果与日志位于 .cache；不会改动自己的课程库。手动验证可导入 samples 中的 PDF/PPTX/代码，检查多文件流程、划词翻译、提问转对话、保存笔记、引用跳转、刷新重启。长 PDF 使用 PDF.js 渲染队列和页面缓存，避免同时绘制全部画布。

可选前端交互状态测试（已有 Node.js 时运行，无需 npm 安装）：

```powershell
node --test tests/frontend_state.mjs tests/frontend_agent.mjs
```

覆盖四标签缓存、笔记模式标记、输入高度、课程栏动画、迟到回复、SSE 分块与 UTF-8 解码。后端使用确定性模型运行真实 Deep Agents，不依赖付费 API，验证本地 MCP 调用、上下文压缩、取消、迁移和课程隔离。
